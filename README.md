## $49.99/年的 KVM 和 $169.99/年的 CN2 GIA-E，差在哪

这个问题是最多人问的。配置纸面上差不多，价格差了三倍多，到底差在哪？

差在网络线路。

KVM 套餐用的是普通国际线路，晚高峰会堵，国内访问延迟不稳定。CN2 GIA-E 走的是中国电信的 CN2 GIA 优化线路——电信、联通、移动三网回程各自走优化通道，延迟低、晚高峰丢包率极低。

我自己两个都用过。白天差距不大，但一到晚上 9 点到 11 点，KVM 套餐的 ping 值能飘到 300ms 以上，CN2 GIA-E 基本稳在 160ms 上下，完全是两个体验。如果你的主要用途是建站或者需要从国内访问服务器，这个差距每天都会感受到。

如果只是学 Linux、跑个轻量级脚本、国际方向用途比较多，$49.99/年的 KVM 足够用。
